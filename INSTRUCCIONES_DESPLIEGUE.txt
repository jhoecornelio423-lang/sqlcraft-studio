====================================================================
INSTRUCCIONES DE DESPLIEGUE (DOCKER / UBUNTU / VPS)
====================================================================

SQLCraft Studio cuenta con soporte nativo para Docker y Nginx.

OPCIÓN 1: Despliegue con Docker Compose (Recomendado)
----------------------------------------------------
1. Clonar el repositorio o copiar el directorio del proyecto al servidor:
   git clone https://github.com/jhoecornelio423-lang/sqlcraft-studio.git
   cd sqlcraft-studio

2. Levantar el servicio en segundo plano:
   docker compose up -d --build

3. Verificar que el contenedor está activo:
   docker compose ps

OPCIÓN 2: Despliegue con Docker CLI
-----------------------------------
1. Construir la imagen de Docker:
   docker build -t sqlcraft:latest .

2. Ejecutar el contenedor en segundo plano (Puerto 80):
   docker run -d -p 80:80 --name sqlcraft --restart always sqlcraft:latest

   (Si el puerto 80 está ocupado, usar por ejemplo 5173 o 8080: -p 8080:80)

OPCIÓN 3: Servidor Local de Desarrollo
--------------------------------------
- Con Python:
  python -m http.server 5173

- Con Node.js / NPM:
  npm start

La aplicación estará accesible en: http://<IP-DEL-SERVIDOR> o http://localhost:5173
